# Borrador, análisis y presentación con Microsoft 365 Copilot

## Plataforma de laboratorios

Te damos la bienvenida a la **plataforma de laboratorios** del curso **Borrador, análisis y presentación con Microsoft 365 Copilot**. Aquí podrás explorar diferentes tecnologías a través de prácticas guiadas. ¡Desarrolla tus habilidades y lleva tus conocimientos al siguiente nivel!

## Lista de laboratorios

Cada uno de estos laboratorios está diseñado para ofrecerte una experiencia práctica. Haz clic en el nombre de la práctica para comenzar. Cuando una práctica utiliza archivos de apoyo, encontrarás los enlaces de descarga directamente debajo de su descripción.

### [Práctica 2. Preparación de una presentación ejecutiva de seguimiento de portafolios modelo](Practica02/README.md)

- **Descripción**: Utilizarás un documento fuente ficticio de CIBEST CAPITAL para planear, crear y refinar una presentación ejecutiva con Microsoft 365 Copilot en PowerPoint, manteniendo la narrativa fiel a la evidencia disponible.
- ⏱️ **Duración estimada**: 36 min.

**Recursos**
- 📄 [Descargar Fuente_Portafolios_Modelo_CIBEST.docx](Practica02/recursos/Fuente_Portafolios_Modelo_CIBEST.docx)

### [Práctica 3. Documentación del proceso de vinculación de un nuevo cliente de inversión](Practica03/README.md)

- **Descripción**: Convertirás notas internas deliberadamente desordenadas en un procedimiento ficticio claro utilizando Copilot en Word, reorganizando la información disponible, eliminando redundancias y marcando como pendiente cualquier información ausente.
- ⏱️ **Duración estimada**: 30 min.

**Recursos**
- 📄 [Descargar Notas_Vinculacion_Cliente_CIBEST.docx](Practica03/recursos/Notas_Vinculacion_Cliente_CIBEST.docx)

### [Práctica 4. Preparación de una reunión para el lanzamiento de un nuevo servicio digital](Practica04/README.md)

- **Descripción**: A partir de un hilo de correo y una conversación ficticia de Teams, recuperarás el estado de una iniciativa de lanzamiento digital, identificarás avances, pendientes, responsables, dependencias, riesgos y decisiones no resueltas, y prepararás objetivos, preguntas y una agenda. La práctica incluye una demostración de recapitulación de una reunión grabada.
- ⏱️ **Duración estimada**: 25 min (18 min de práctica + 7 min de demostración).

**Recursos**
- 📄 [Abrir Conversacion_Teams_Lanzamiento.md](Practica04/recursos/Conversacion_Teams_Lanzamiento.md)
- 📄 [Abrir Guion_Reunion_Demo.md](Practica04/recursos/Guion_Reunion_Demo.md)
- 📁 [Ver y descargar los archivos de correo de la práctica](https://github.com/Netec-Mx/Custom-MS-4018-ESP-CC-LD-Priv-/tree/main/Practica04/recursos/correo_lanzamiento)

### [Práctica 5. Análisis del proceso de apertura de cuentas y detección de excepciones operativas](Practica05/README.md)

- **Descripción**: Analizarás un conjunto de 500 solicitudes ficticias de apertura de cuentas con Copilot en Excel para identificar patrones observables relacionados con volumen, tiempos, estados, documentación pendiente, incidencias y valores atípicos.
- ⏱️ **Duración estimada**: 35 min.

**Recursos**
- 📊 [Descargar Apertura_Cuentas_500_Solicitudes.xlsx](Practica05/recursos/Apertura_Cuentas_500_Solicitudes.xlsx)

### [Práctica 6. Gestión de una solicitud de documentación pendiente para la apertura de una cuenta](Practica06/README.md)

- **Descripción**: Utilizarás Copilot en Outlook para resumir un hilo ficticio de ocho mensajes, identificar documentos pendientes y compromisos, redactar una respuesta al cliente y preparar una reunión interna breve sin introducir requisitos ajenos al escenario.
- ⏱️ **Duración estimada**: 31 min.

**Recursos**
- 📁 [Ver y descargar los ocho archivos de correo de la práctica](https://github.com/Netec-Mx/Custom-MS-4018-ESP-CC-LD-Priv-/tree/main/Practica06/recursos/hilo_documentacion)

### [Práctica 7. Análisis preliminar del crecimiento de los ETFs activos como oportunidad de conversación comercial](Practica07/README.md)

- **Descripción**: Utilizarás Microsoft 365 Copilot Chat para investigar la evolución reciente de los ETFs gestionados activamente, mejorar la indicación con Prompt Coach, contrastar fuentes y organizar los resultados en una Página de Copilot.
- ⏱️ **Duración estimada**: 28 min.
- **Recursos**: No requiere archivos previos.
