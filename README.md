# Borrador, análisis y presentación con Microsoft 365 Copilot

MS-4018: Redactar, analizar y presentar con Microsoft 365 Copilot enseña a los estudiantes a usar Copilot y agentes para completar flujos de trabajo del mundo real en las aplicaciones de Microsoft 365. El curso destaca cómo Copilot ayuda a lograr objetivos empresariales clave, como redactar contenido, analizar datos, prepararse para reuniones y gestionar las comunicaciones. Los alumnos también ven cómo Copilot Chat, las experiencias en la aplicación y los agentes funcionan juntos para combinar el contexto organizativo y la intención del usuario en todo el trabajo diario.

## Estructura

- `CapituloXX/README.md`: guía de laboratorio por capítulo.

## Lista de laboratorios

### Capítulo 2

- [Preparación de una presentación ejecutiva de seguimiento de portafolios modelo (CIBEST CAPITAL)](Capitulo02/README.md#preparación-de-una-presentación-ejecutiva-de-seguimiento-de-portafolios-modelo-cibest-capital)

  A partir de información ficticia sobre tres portafolios modelo, utilizarás Copilot en PowerPoint y el Entrenador de ideas para definir la narrativa, crear y reorganizar una presentación ejecutiva, mejorar sus textos y elementos visuales, preparar un resumen ejecutivo y generar notas para su exposición.

  - Duración estimada: 36 min

### Capítulo 3

- [Documentación del proceso de vinculación de un nuevo cliente de inversión (CIBEST CAPITAL)](Capitulo03/README.md#documentación-del-proceso-de-vinculación-de-un-nuevo-cliente-de-inversión-cibest-capital)

  Utilizarás Copilot en Word para transformar notas internas desestructuradas en un procedimiento claro de vinculación de clientes, reorganizando la información, eliminando redundancias, convirtiendo requisitos en una tabla, generando un resumen y revisando la claridad del documento con el Asesor de escritura.

  - Duración estimada: 30 min

### Capítulo 4

- [Preparación de una reunión para el lanzamiento de un nuevo servicio digital (CIBEST CAPITAL)](Capitulo04/README.md#preparación-de-una-reunión-para-el-lanzamiento-de-un-nuevo-servicio-digital-cibest-capital)

  A partir de un correo y una conversación ficticia de Teams, utilizarás Copilot para recuperar el contexto de una iniciativa, identificar avances, pendientes, responsables, dependencias y decisiones abiertas, y preparar los objetivos, preguntas y agenda para una reunión de seguimiento.

  - Duración estimada: 18 min

- [Demo: Recuperación de acuerdos, decisiones y actividades desde una reunión grabada con Intelligent Recap](Capitulo04/README.md#demo-recuperación-de-acuerdos-decisiones-y-actividades-desde-una-reunión-grabada-con-intelligent-recap)

  El instructor demostrará cómo utilizar las capacidades de recapitulación de Teams sobre una reunión previamente grabada para recuperar acuerdos, decisiones y actividades posteriores relacionadas con el escenario trabajado en la práctica.

  - Duración estimada: 7 min

### Capítulo 5

- [Análisis del proceso de apertura de cuentas y detección de excepciones operativas (CIBEST CAPITAL)](Capitulo05/README.md#análisis-del-proceso-de-apertura-de-cuentas-y-detección-de-excepciones-operativas-cibest-capital)

  Utilizarás Copilot en Excel para analizar solicitudes ficticias de apertura de cuentas, identificar indicadores, tendencias, incidencias, solicitudes pendientes y valores atípicos, generar fórmulas, resúmenes, tablas dinámicas y visualizaciones, y determinar qué elementos requieren mayor seguimiento operativo.

  - Duración estimada: 35 min

### Capítulo 6

- [Gestión de una solicitud de documentación pendiente para la apertura de una cuenta (CIBEST CAPITAL)](Capitulo06/README.md#gestión-de-una-solicitud-de-documentación-pendiente-para-la-apertura-de-una-cuenta-cibest-capital)

  Utilizarás Copilot en Outlook para resumir un hilo de correos, identificar documentación y compromisos pendientes, redactar y mejorar una respuesta al cliente y preparar el objetivo y la agenda de una reunión interna necesaria para resolver un punto de coordinación.

  - Duración estimada: 31 min

### Capítulo 7

- [Análisis preliminar del crecimiento de los ETFs activos como oportunidad de conversación comercial (CIBEST CAPITAL)](Capitulo07/README.md#análisis-preliminar-del-crecimiento-de-los-etfs-activos-como-oportunidad-de-conversación-comercial-cibest-capital)

  Utilizarás Copilot Chat, Prompt Coach, búsqueda web y el agente Investigador para realizar un análisis preliminar sobre los ETFs gestionados activamente, contrastar información y fuentes, identificar tendencias y factores de crecimiento, formular preguntas pendientes y organizar los resultados en una Página de Copilot.

  - Duración estimada: 28 min
